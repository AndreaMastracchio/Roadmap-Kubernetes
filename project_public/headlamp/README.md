# Corso Headlamp: Governare Kubernetes con una Dashboard

Benvenuto nel percorso formativo dedicato a **Headlamp**, la web UI open source per Kubernetes
che ti permette di gestire i tuoi cluster da browser o da applicazione desktop, senza rinunciare
a kubectl ma senza doverlo digitare a mano.

## Cosa imparerai in questo viaggio
- **Installazione Multi-Piattaforma**: desktop app per macOS, Windows e Linux, oppure deployment in-cluster.
- **Collegamento dei Cluster**: token, certificati e OIDC, con rispetto dei permessi RBAC.
- **Navigazione dell'Interfaccia**: dashboard, lista risorse, dettagli e action contestuali.
- **Gestione dei Workload**: deployment, pod, scale, restart, rollback e editor YAML.
- **Log e Terminale**: visualizzazione log, terminale interattivo nei pod e port-forward.
- **Configurazione e Segreti**: ConfigMap, Secret e Storage con una UI sicura.
- **Monitoraggio e Multicluster**: metriche, switch rapido tra cluster e vista aggregata.
- **Projects, Plugin e AI**: vista applicativa multi-cluster, estensione con plugin e assistente AI.

## Struttura del Corso
Il corso è diviso in **10 moduli interattivi** che combinano teoria, quiz di verifica e sfide
pratiche. Al termine di ogni modulo potrai testare le tue conoscenze e, alla fine del percorso,
affrontare l'**Esame Finale** per validare le tue competenze.
