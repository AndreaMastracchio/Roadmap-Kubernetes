# 10. Esame Finale

Hai completato il corso: ora verifichiamo che sai **usare Headlamp da solo**.

## Cosa devi saper fare
- Connettere Headlamp a un cluster reale in modo sicuro (ServiceAccount + RBAC e accesso limitato ai
  namespace).
- Navigare senza affanno: Home, nodi, workloads, network, config, storage.
- Operare su un Deployment dalla UI: dettaglio, edit YAML, scale, restart.
- Consultare log e terminale di un pod (con i relativi permessi).
- Capire il ruolo di Metrics Server per le metriche della Home.
- Identificare e usare il selettore cluster per il multi-cluster.
- Gestire ConfigMap e Secret rispettando la sicurezza (niente segreti in chiaro senza ragione).
- Creare un Project applicativo e installare un plugin dal catalogo.

## Come funziona l'esame
- **5 domande** a scelta multipla, di difficoltà mista.
- **3 esercitazioni pratiche** guidate: completa i blocchi e verifica il risultato sul tuo cluster.

> Ricorda: Headlamp è uno strumento. Lo padroneggi davvero quando riesci a fare con la UI — in
> meno tempo e con meno errori — quello che prima facevi solo con kubectl.
